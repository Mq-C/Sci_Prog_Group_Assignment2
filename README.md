# Scientific Programming Group Assignment 2

# Objective:

# The program performed a flood analysis exposure in a specific case. The case study is located in Derna, Libya, which was affected on September 2023 for a flood. The program is supported by functions, which are: prepare layers, raster clipping, vector clipping, and zonal statistics for floods. For running the program, unzip the folder shared and run the main_code.py. Some Paths should be adjusted for the local machine.

# As outputs, the program printed basic information about the event, some tables with summary information, and different charts and plots for visualization and support the analysis.

# As a visualization, the program also provided an interactive map as a Jupyter notebook. This file should be run in addition to the main function. The map shows, using satellite imagery, the flood extent and the physical elements affected after the floods, such as roads and buildings.

# Data Setup:
# The original information for the project was derived from:

# Flood extent from https://unosat.org/products/3671
# Buildings from https://data.humdata.org/dataset/buildings-footprint-floods-derna-libya

# Population 2020 -2024 from https://data.humdata.org/dataset/worldpop-population-counts-2015-2030-lby
# Simulated water depth from https://mapping.emergency.copernicus.eu/activations/EMSN177/
